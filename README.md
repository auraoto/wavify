# Wavify - Музыкальный плеер

Современное десктопное и веб-приложение для прослушивания музыки, с поддержкой поиска по стриминговым платформам (**Deezer**, **Яндекс.Музыка**, **SoundCloud**), витриной альбомов с точными годами выпуска, полноформатным воспроизведением треков, текстами песен с Genius, кастомизацией темы и выбором языка (Русский / English).

## 🚀 Быстрый запуск

### Способ 1: Десктопное приложение через pywebview (Рекомендуется)
```bash
cd /home/whywithme/.gemini/antigravity/scratch/wavify
python3 main.py
```
Запустит нативное окно программы с аппаратным ускорением, сохранением плейлистов и настроек.

### Способ 2: В веб-браузере
```bash
cd /home/whywithme/.gemini/antigravity/scratch/wavify
python3 server.py 3000
```
После запуска перейдите в браузере по адресу: **http://localhost:3000**

## ✨ Основные возможности

1. **Десктопное приложение на pywebview**:
   - Нативное окно WebKitGTK с современным дизайном без рамок браузера.
   - Полноценное сохранение пользовательских плейлистов, языка и темы оформления.

2. **Поиск по стримингам и честные источники**:
   - Единая поисковая строка с защитой от гонки запросов и кэшированием.
   - Поддерживаемые платформы:
     - 🟣 **Deezer**
     - 🟡 **Яндекс.Музыка**
     - 🟠 **SoundCloud**
   - Возможность переключения между сервисами и поиск по всем платформам сразу.
   - Анимированный переход поисковой строки из центра наверх при вводе.

3. **Настройки (меню «...» в правом верхнем углу)**:
   - **Акцентный цвет**: палитра пресетов + нативный color picker (мгновенно меняет цвет логотипа, активных треков, прогресс-баров и кнопок).
   - **Название**: возможность переименовать сайт (изменяется в облачном логотипе, вкладке браузера и заголовке).
   - **Язык**: моментальное переключение между **Русским (RU)** и **Английским (EN)**.
   - Все настройки автоматически сохраняются в `localStorage`.

4. **Рабочий аудиоплеер**:
   - Воспроизведение аудио через HTML5 Audio + резервный гармонический синтезатор Web Audio API.
   - Поддержка горячих клавиш:
     - `Space` — Пауза / Воспроизведение
     - `Стрелка вправо / влево` — Перемотка на 5 секунд
     - `Стрелка вверх / вниз` — Регулировка громкости
     - `Alt + Стрелки` — Навигация по истории (Назад / Вперед)
   - Режимы повтора (все / один трек) и регулировка громкости с отключением звука.

5. **Управление плейлистами**:
   - Создание новых плейлистов через кнопку `+` в сайдбаре.
   - Добавление треков в избранное / плейлисты через кнопку `+` в нижнем плеере.
   - Просмотр треков в альбомах и плейлистах.
